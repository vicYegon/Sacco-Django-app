# 1. REGISTER MEMBER
Officer enters member information
            ↓
System validates information
            ↓
Check for duplicate records
            ↓
Submit application
            ↓
Authorized officer reviews
            ↓
Approve / Reject
            ↓
Generate membership number
            ↓
Record audit event

# 2. RECORD CONTRIBUTION
Select member
      ↓
Select savings/contribution product
      ↓
Enter amount and payment reference
      ↓
Validate transaction
      ↓
Check duplicate reference
      ↓
Post transaction
      ↓
Update member statement
      ↓
Record audit event

# 3. APPLY FOR LOAN
Member selects loan product
            ↓
Enter amount + duration + purpose
            ↓
Check eligibility
            ↓
Request guarantors
            ↓
Guarantors respond
            ↓
Loan officer reviews
            ↓
Approve / Reject
            ↓
Record decision
