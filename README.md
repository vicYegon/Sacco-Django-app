# SACCO Platform

## Purpose

A secure and scalable web platform for managing SACCO membership,
savings, contributions, loans, guarantors, repayments and statements.

## Target Users

- SACCO Members
- SACCO Officers
- Loan Officers
- Accountants
- Administrators
- Auditors

## Technology Stack

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL
- Redis
- Celery

### Frontend
- JavaScript
- React
- Vite

### Infrastructure
- Docker
- GitHub Actions

## Architecture

The application will initially use a modular monolith architecture.

Planned backend modules include:

- Accounts
- Members
- Savings
- Loans
- Guarantors
- Transactions
- Notifications
- Reports
- Audit
- Integrations

## Current Status

Project setup and development environment configuration.

## Target

Controlled MVP pilot during the first week of January 2027.

## Development Safety

Development and testing will use synthetic or anonymized information.

Real SACCO member information and real financial transactions will not
be used until the application has undergone security review, user
acceptance testing and production approval.
